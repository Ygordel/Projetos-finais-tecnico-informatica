## 📚 Sobre o Projeto

Este repositório reúne propostas e orientações para o desenvolvimento dos **Projetos Finais do Curso Técnico em Informática**.

Os projetos foram planejados para alunos do **Ensino Médio Técnico**, priorizando soluções:

- atuais;
- simples de desenvolver;
- funcionais;
- relacionadas ao cotidiano;
- possíveis de executar com os recursos disponíveis no laboratório;
- capazes de integrar diferentes conhecimentos da formação técnica.

> **A proposta não é criar um sistema comercial complexo. O objetivo é demonstrar, na prática, aquilo que o aluno aprendeu durante o curso.**

---

# 🎯 Objetivo

Desenvolver uma solução tecnológica para um problema real ou próximo da realidade do aluno, utilizando conhecimentos de:

- 🌐 Redes de Computadores;
- 💻 Programação;
- 🖥️ Desenvolvimento Web;
- 🗄️ Banco de Dados;
- 🔐 Segurança da Informação;
- 🧩 Organização e documentação de projetos.

---

# 🚀 Como será o projeto

Cada equipe deverá:

1. escolher uma proposta;
2. identificar o problema;
3. definir uma solução;
4. levantar os requisitos;
5. planejar o banco de dados;
6. desenvolver a aplicação;
7. testar;
8. documentar;
9. apresentar o projeto.

A equipe deverá demonstrar **como os conhecimentos de diferentes áreas foram utilizados na solução**.
