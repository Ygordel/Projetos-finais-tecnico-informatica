# 🖥️ PROJETO 03 — INVENTÁRIO DE COMPUTADORES

## Sistema de Controle de Equipamentos de Informática

> **Projeto Final — Curso Técnico em Informática | Ensino Médio Técnico**

---

# 1. 📚 APRESENTAÇÃO

O **Inventário de Computadores** é uma proposta de aplicação web destinada ao cadastro, organização e acompanhamento dos equipamentos de informática existentes em uma escola, laboratório ou setor de tecnologia.

Em um ambiente com vários computadores, é importante conhecer as características de cada equipamento, sua localização, seu endereço de rede e sua situação atual.

O sistema permitirá centralizar essas informações em um único local.

O projeto integra conhecimentos de:

- 🌐 Redes de Computadores;
- 💻 Programação;
- 🖥️ Desenvolvimento Web;
- 🗄️ Banco de Dados;
- 🛠️ Montagem e Manutenção de Computadores;
- 🔐 Segurança da Informação.

> **A proposta foi pensada para alunos do Ensino Médio Técnico em Informática, utilizando recursos que podem ser desenvolvidos gradualmente durante as aulas.**

---

# 2. 🎯 OBJETIVO GERAL

Desenvolver uma aplicação web para cadastrar, consultar, pesquisar e acompanhar informações relacionadas aos computadores e equipamentos de informática de uma escola ou laboratório.

---

# 3. 🎯 OBJETIVOS ESPECÍFICOS

A equipe deverá:

- desenvolver uma aplicação web;
- cadastrar laboratórios;
- cadastrar computadores;
- cadastrar equipamentos;
- registrar informações de hardware;
- registrar informações de rede;
- controlar a situação dos equipamentos;
- registrar manutenções;
- realizar pesquisas;
- gerar informações para consulta;
- utilizar banco de dados;
- aplicar conceitos de redes;
- aplicar conhecimentos de montagem e manutenção;
- realizar testes;
- documentar o projeto;
- organizar o trabalho no GitHub.
