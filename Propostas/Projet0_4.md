# 🌐 PROJETO 04 — CONECTA ESCOLA

## Sistema Web de Monitoramento e Diagnóstico de Rede Escolar

> **Projeto Final — Curso Técnico em Informática | Ensino Médio Técnico**

---

# 1. 📚 APRESENTAÇÃO

O **Conecta Escola** é uma proposta de aplicação web para auxiliar no acompanhamento básico da rede de computadores de uma escola.

Em um ambiente escolar, diversos computadores, impressoras, servidores e outros dispositivos dependem da rede para acessar sistemas e serviços.

Quando um equipamento perde a conexão, apresenta lentidão ou não consegue acessar determinado serviço, é necessário identificar o problema de forma organizada.

A proposta deste projeto é desenvolver uma aplicação simples que permita cadastrar dispositivos, registrar informações de rede e realizar verificações básicas de conectividade.

O projeto integra conhecimentos de:

- 🌐 Redes de Computadores;
- 💻 Programação;
- 🖥️ Desenvolvimento Web;
- 🗄️ Banco de Dados;
- 🛠️ Montagem e Manutenção;
- 🔐 Segurança da Informação.

> **O projeto foi planejado para alunos do Ensino Médio Técnico em Informática e poderá ser desenvolvido utilizando os computadores disponíveis no laboratório.**

---

# 2. 🎯 OBJETIVO GERAL

Desenvolver uma aplicação web capaz de organizar informações dos dispositivos de uma rede escolar e auxiliar na realização de verificações básicas de conectividade.

---

# 3. 🎯 OBJETIVOS ESPECÍFICOS

A equipe deverá:

- desenvolver uma aplicação web;
- cadastrar dispositivos;
- cadastrar laboratórios;
- registrar endereços IP;
- registrar endereços MAC;
- registrar hostname;
- identificar o tipo de dispositivo;
- consultar dispositivos;
- pesquisar por endereço IP;
- verificar conectividade;
- registrar ocorrências;
- armazenar informações no banco de dados;
- aplicar conceitos de redes;
- utilizar programação;
- realizar testes;
- documentar o projeto;
- disponibilizar o trabalho no GitHub.
