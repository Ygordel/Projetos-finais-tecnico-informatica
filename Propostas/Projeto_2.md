# 🎫 PROJETO 02 — HELP DESK ESCOLAR

## Sistema de Chamados de Suporte Técnico

> **Projeto Final — Curso Técnico em Informática | Ensino Médio Técnico**

---

# 1. 📚 APRESENTAÇÃO

O **Help Desk Escolar** é uma proposta de aplicação web destinada ao registro, acompanhamento e organização de solicitações de suporte técnico em uma escola.

Em um ambiente com diversos computadores, impressoras, pontos de rede e outros equipamentos, é comum surgirem problemas que precisam ser registrados e acompanhados.

A proposta deste projeto é desenvolver um sistema simples no qual professores, alunos ou funcionários possam registrar problemas de informática e a equipe responsável possa acompanhar o atendimento.

O projeto integra conhecimentos de:

- 🌐 Redes de Computadores;
- 💻 Programação;
- 🖥️ Desenvolvimento Web;
- 🗄️ Banco de Dados;
- 🛠️ Montagem e Manutenção de Computadores;
- 🔐 Segurança da Informação.

> **O objetivo não é desenvolver um sistema comercial complexo. A proposta é criar uma solução funcional e adequada ao nível dos alunos do Ensino Médio Técnico em Informática.**

---

# 2. 🎯 OBJETIVO GERAL

Desenvolver uma aplicação web para registrar, consultar e acompanhar chamados relacionados a problemas de informática em um ambiente escolar.

---

# 3. 🎯 OBJETIVOS ESPECÍFICOS

A equipe deverá:

- criar uma aplicação web;
- criar cadastro de usuários;
- criar cadastro de equipamentos;
- permitir abertura de chamados;
- permitir consulta dos chamados;
- permitir alteração do status;
- registrar diagnóstico;
- registrar solução;
- utilizar banco de dados;
- utilizar conceitos de redes;
- realizar testes;
- documentar o projeto;
- disponibilizar o trabalho no GitHub.

---

# 4. 💡 SITUAÇÃO-PROBLEMA

Imagine uma escola com três laboratórios de informática.

Cada laboratório possui diversos computadores.

Durante uma aula, um aluno percebe que o computador utilizado não consegue acessar a Internet.

O aluno informa o problema ao professor.

Sem um sistema de controle, essa informação pode ser perdida ou esquecida.

Com o Help Desk Escolar, o problema poderá ser registrado:
