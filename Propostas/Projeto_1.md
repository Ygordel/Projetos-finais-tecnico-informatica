# 🔐 PROJETO 01 — CYBERSCHOOL

## Plataforma de Segurança Digital para Estudantes

> **Projeto Final — Curso Técnico em Informática | Ensino Médio Técnico**

---

# 1. 📚 APRESENTAÇÃO

O **CyberSchool** é uma proposta de aplicação web educativa voltada para a conscientização sobre segurança digital.

O projeto foi desenvolvido pensando na realidade dos estudantes do Ensino Médio Técnico em Informática, utilizando conceitos estudados durante o curso.

A proposta é criar uma aplicação simples, funcional e didática, permitindo que os alunos desenvolvam uma solução tecnológica sem depender de recursos avançados.

O projeto integra conhecimentos de:

- 🌐 Redes de Computadores;
- 💻 Programação;
- 🖥️ Desenvolvimento Web;
- 🗄️ Banco de Dados;
- 🔐 Segurança da Informação.

> **O objetivo é desenvolver um projeto possível de ser realizado pelos alunos e, ao mesmo tempo, demonstrar a integração dos conhecimentos adquiridos durante o curso.**

---

# 2. 🎯 OBJETIVO GERAL

Desenvolver uma aplicação web educativa capaz de apresentar situações simuladas de segurança digital e avaliar o conhecimento do usuário por meio de perguntas e respostas.

---

# 3. 🎯 OBJETIVOS ESPECÍFICOS

A equipe deverá:

- desenvolver uma aplicação web;
- criar uma interface simples e intuitiva;
- criar cadastro de usuários;
- implementar login;
- apresentar questões sobre segurança digital;
- permitir o envio das respostas;
- calcular a pontuação;
- apresentar o resultado;
- armazenar os resultados;
- utilizar banco de dados;
- aplicar conceitos básicos de redes;
- realizar testes;
- documentar o projeto;
- utilizar o GitHub para organização do trabalho.

---

# 4. 💡 SITUAÇÃO-PROBLEMA

Atualmente, estudantes utilizam computadores, smartphones, redes sociais e serviços de Internet diariamente.

Com isso, também estão sujeitos a situações como:

- mensagens falsas;
- links suspeitos;
- phishing;
- senhas fracas;
- perfis falsos;
- páginas fraudulentas;
- exposição de informações pessoais.

## Exemplo

Um estudante recebe:

> **"Sua conta será bloqueada hoje. Clique neste link e informe sua senha para confirmar seus dados."**

O estudante precisa analisar a situação e decidir qual seria a atitude mais segura.

O **CyberSchool** deverá apresentar situações semelhantes para que o usuário possa testar seus conhecimentos.
